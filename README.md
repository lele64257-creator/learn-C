# C Learning Repository

This repository contains C programming examples and exercises for learning foundational language concepts.

## Goals
- Learn C fundamentals step by step
- Practice with small programs and book exercises
- Build confidence compiling and running C code
- Improve README and documentation skills

### Using Visual Studio Code
1. Open this folder in VS Code.
2. Use the C/C++ build task or run the active file with the configured GCC toolchain.
3. Check the `build/` and `output/` folders for generated artifacts.

## Notes
- Most source files are small practice programs.
- File names reflect the learning topic or exercise.
- The repository includes book review programs and test programs.
